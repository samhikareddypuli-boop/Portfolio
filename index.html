Timeline

Core Tech

01 / Challenge

Bridging software logic with physical electrical components introduces hardware-level challenges. Reading telemetry from environmental sensors in real-time requires managing noise, voltage fluctuations, connection drops, and optimizing communication frequency to conserve power on edge boards.

02 / Plan

The project plan focused on establishing sensor-to-cloud pipelines:

  • Interfacing temperature, humidity, and light sensors with microcontrollers (ESP8266/ESP32).
  • Writing robust firmware in C++ featuring automatic network reconnect loops.
  • Selecting the MQTT protocol for lightweight, low-overhead message broker communication.
03 / Execution

During the workshop, I constructed the physical sensor circuits on breadboards and programmed the microcontrollers. I configured the ESP8266 to connect to local networks, calibrated sensor readings, formatted data packets, and set up a Node-RED subscription dashboard on a local gateway server to visualize active temperature curves.

04 / Outcome

The hands-on project successfully streamed continuous weather data over 24 hours. The work was awarded the official IoT Workshop Certificate, demonstrating capability in embedded systems programming and IoT telemetry network integrations.
